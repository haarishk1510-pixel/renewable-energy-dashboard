# 📌 Overview

The **Renewable Energy Dashboard** is a web-based application that enables users to monitor renewable energy information, analyse energy production, and generate AI-based predictions using Machine Learning models.

The system combines an interactive dashboard, SQLite database management, prediction history, and intelligent forecasting into a single platform for efficient renewable energy management.

# 🚀 System Modules

### 📊 Executive Dashboard

Displays renewable energy statistics and system overview through an intuitive dashboard.

### 🤖 AI Energy Predictor

Uses trained Machine Learning models to predict renewable energy generation.

### 🗄️ Database Storage Portal

Stores and manages renewable energy records using SQLite.

### 📈 Prediction History

Maintains previous predictions for analysis and comparison.

### 📋 System Audit Logs

Tracks application activities and system operations.

### ⚙️ System Controller

Provides administrative controls for managing dashboard operations.

# 🧠 Machine Learning Models

The application integrates multiple Machine Learning models for accurate prediction.

- Linear Regression
- Random Forest Regression

Trained models are stored inside the **models/** directory and loaded dynamically during prediction.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/haarishk1510-pixel/renewable-energy-dashboard.git
```

Navigate into the project

```bash
cd renewable-energy-dashboard
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
